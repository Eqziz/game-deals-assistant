# Game Deals Assistant

Сервис сравнения скидок на PC-игры из CheapShark и Steam. Поиск, цены в USD и фильтры доступны всем. Вход через Google открывает избранное, сохранение желаемой цены и библиотеку игр. Синхронизация Steam использует публичную библиотеку по SteamID64. Интерфейс доступен на русском и английском.

## Локальный запуск

1. Установите Docker с Compose. Скопируйте `.env.example` в `.env` и заполните настройки из примера.
2. Зарегистрируйте OAuth-клиент Google типа Web application. Для локальной разработки укажите `PUBLIC_BASE_URL=http://localhost:8000` и разрешённый адрес возврата `http://localhost:8000/auth/callback`. Значения `GOOGLE_CLIENT_ID` и `GOOGLE_CLIENT_SECRET` принадлежат одной конфигурации клиента.
3. Запустите `docker compose up --build` и откройте http://localhost:8000. Compose поднимает PostgreSQL с постоянным томом. Для импорта Steam задайте `STEAM_API_KEY`.

Для запуска напрямую установите зависимости из `requirements.txt`, экспортируйте переменные окружения, задайте `DATABASE_URL` для PostgreSQL и выполните `python -m uvicorn app.main:app --port 8000`. Для `SESSION_SECRET` используйте случайное значение длиной не менее 32 символов. Его можно создать командой `python -c "import secrets; print(secrets.token_urlsafe(48))"`.

## Проверки

Для тестов создайте отдельную базу PostgreSQL и задайте `TEST_DATABASE_URL`. Тестовый пользователь должен иметь права создавать схемы. Выполните `python -m pip install pytest`, затем `python -m pytest`. Набор проверяет публичные и личные маршруты, изоляцию двух аккаунтов, отзыв сессии, отказ внешнего источника и повтор запроса. Данные тестов размещаются во временной схеме. Ответы игровых сервисов подменяются в тестах.

## Выпуск в Render

Подключите репозиторий как Blueprint из `render.yaml`. Для постоянного внешнего PostgreSQL задайте предоставленный провайдером `DATABASE_URL`, включая параметры TLS. Используйте публичный HTTPS-адрес сервиса для `PUBLIC_BASE_URL` и зарегистрируйте тот же адрес с путём `/auth/callback` в Google Cloud. Задайте секреты через настройки окружения Render. Для публичного входа OAuth-приложение Google должно разрешать вход целевой аудитории.

Перед обновлением существующей PostgreSQL-базы создайте резервную копию командой `pg_dump --format=custom --file=before-release.dump` с параметрами подключения через окружение libpq. Восстановите архив через `pg_restore --exit-on-error --no-owner --dbname=<пустая_проверочная_база> before-release.dump` и проверьте в копии число игр и избранных предложений по пользователям. Храните архив вне репозитория. При переходе со старой версии сохраните SQLite-файл с помощью SQLite Backup API. Общий профиль `demo@local` нельзя автоматически привязать к вошедшему пользователю.

После публикации проверьте `/api/health`, загрузку каталога, вход через Google и сохранение избранной игры. Откройте её в другом браузере под тем же аккаунтом, затем повторите проверку после перезапуска сервиса. Под вторым аккаунтом библиотека должна быть отдельной.
