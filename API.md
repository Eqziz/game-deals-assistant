# HTTP API

Цены передаются в USD. Каталог учитывает регион US. Эндпоинты возвращают JSON, кроме главной страницы и перенаправлений входа. Интерактивная схема доступна по адресу `/docs`.

## Доступ и сессия

| Метод и путь | Результат |
| --- | --- |
| `GET /api/health` | Готовность приложения и PostgreSQL. При недоступной базе возвращает HTTP 503. |
| `GET /api/me` | Для гостя `{"authenticated":false,"user":null}`. После входа объект `user` содержит `name` и `email`. |
| `GET /auth/login?next=/` | Начало входа через Google. Параметр возврата допускает локальный путь. |
| `GET /auth/callback` | Проверка ответа Google, создание сессии и возврат в приложение. |
| `POST /auth/logout` | Отзыв текущей сессии. |

Для личных данных требуется действующая cookie сессии. Браузер передаёт её автоматически. Мутации с cookie требуют подтверждения того же источника запроса. Отсутствующая или истёкшая сессия на личных маршрутах даёт HTTP 401.

## Каталог

`GET /api/stores` возвращает `featured` и `all` с идентификаторами и названиями источников. `GET /api/deals` возвращает `deals` и `next_page`. Значение `null` означает конец выдачи. Для догрузки передайте полученный номер страницы с прежними фильтрами.

| Параметры | Назначение |
| --- | --- |
| `source`, `store_id` | `source=steam` для прямой выдачи Steam или идентификатор магазина CheapShark. |
| `title` | Поиск по названию игры. |
| `min_discount`, `max_discount` | Границы скидки в процентах от 0 до 100. По умолчанию 10 и 100. |
| `max_price`, `free_only` | Верхняя граница цены или только бесплатные предложения. |
| `hide_owned` | Скрыть игры из библиотеки текущего пользователя. |
| `page`, `page_size` | Начальная страница 0. От 1 до 100 предложений за запрос. |

Предложение содержит название, магазин, текущую и обычную цены, процент скидки, ссылку на магазин, обложку при наличии, признаки `owned` и `is_favorite`.

## Личные данные

| Метод и путь | Назначение |
| --- | --- |
| `GET /api/favorites` | Избранное текущего аккаунта. |
| `POST /api/favorites` | Сохранить или обновить предложение. Поля: `title`, `store_name`, `deal_url`, `sale_price`, `normal_price`, `savings`. Необязательное поле `target_price` задаётся с точностью до цента. |
| `DELETE /api/favorites/{id}` | Удалить предложение по идентификатору. |
| `POST /api/favorites/delete-by-url` | Удалить по `deal_url`. |
| `GET /api/owned-games` | Библиотека аккаунта. |
| `POST /api/owned-games/manual` | Добавить игру с `platform` и `title`. Опционально передать `platform_game_id` и `playtime_minutes`. |
| `DELETE /api/owned-games/{id}` | Удалить игру из библиотеки. |
| `GET /api/accounts` | Подключённые игровые аккаунты. |
| `POST /api/steam/sync` | Импортировать доступные игры. Передать `steam_id` строкой из 17 цифр. |
